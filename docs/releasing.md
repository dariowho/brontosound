# Releasing

`npm run release` runs [standard-version](https://github.com/conventional-changelog/standard-version): it reads the [Conventional Commits](https://www.conventionalcommits.org/) since the last tag, picks the version bump, writes `CHANGELOG.md`, commits and tags. Then `git push --follow-tags origin main`.

- `npm run release:dry` — preview, writes nothing.
- `npm run release -- --release-as minor` — force a bump level.
- Bumped files: `package.json`, `package-lock.json`, `src/lib/version.json`.
- `src/lib/version.json` is generated by `scripts/update-version.js` (a `precommit` hook) and rendered in the app footer. Never edit it by hand.
- Commit types and their changelog sections are configured under `standard-version` in `package.json`. Hidden types (`chore`, `test`, `docs`, …) still bump nothing and stay out of the changelog.
- Commits before `v0.1.0` predate the convention; the changelog starts there.
