Brontosound

Set up Brontosound

Brontosound needs a .env file with the secret that signs people in, and a data/ folder for your band's settings, database and files. To create what's missing, run this in the Brontosound folder:

npm run init

It asks for your band's name and a password for the admin user. Then reload this page and sign in as admin.

Reload this page

With Docker, run it in your Brontosound checkout, then pass what it creates: --env-file .env -v ./data:/app/data.
